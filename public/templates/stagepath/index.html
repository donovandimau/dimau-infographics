Steps · who holds each one, and for how long

Stagepath

A journey of stages. Each one shows who holds it, how long it usually takes and what happens. The bar shows where the time goes: press a part to jump to that step. Press a name to see only the steps that holder is responsible for.

Real dataThe lease steps from the Vanua OS lease desk, 12 Nov 2026. Usual days are working targets for chasing, not legal deadlines.

Options

  • photo: '/your-photo.jpg' in the data puts a photograph behind the title, as in the Vanua OS lease desk. This page is shown without one: the library does not carry an app's photographs.
  • { tick: true, storageKey: 'my-steps' } gives every step a checkbox, counts “x of n done” and remembers the ticks.
  • { select: true } makes each card a button and tells the app which one was chosen. Add { sequence: false } when the cards are choices, not steps: no numbers, arrows or rail.
  • { bar: false } leaves out the bar. With no amounts the headline counts the steps; with no holders the cards take their colours in turn.
  • Colours: one per holder from --di-c-<holder-name> (for example --di-c-tltb), otherwise the palette --sp-c1 to --sp-c6, which an app can set on the container.
  • Strict style policy: the template writes no style attributes. Serve /v1/stagepath.css yourself as <link id="sp-style" rel="stylesheet"> and the script adds no style element.
